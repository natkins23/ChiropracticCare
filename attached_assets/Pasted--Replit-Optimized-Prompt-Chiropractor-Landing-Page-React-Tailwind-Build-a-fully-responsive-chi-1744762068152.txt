🎨 Design Notes (AI Instructions)
Use soft blue and white tones, modern sans-serif font (Inter or Lato), and full-width spacing with good padding.

All sections should be mobile-first and responsive.

Add focus-visible styles, semantic headings, alt text on images, and respect prefers-reduced-motion.

Use Tailwind's utilities for spacing, color, responsiveness, and font styles.

Animate sections subtly on scroll using framer-motion or CSS transitions.
